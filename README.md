# style-guide-project

Руководство по стилю для документации сервиса TaskFlow (учебный проект).
Правила написания и оформления текстов хранятся как код: в Markdown-файлах, с проверкой линтером и автоматической публикацией.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Сайт откроется по адресу <http://127.0.0.1:8000>.
