# Шаблон: инструкция

Используйте шаблон для документов, которые отвечают на вопрос «Как сделать?».
Скопируйте структуру ниже и заполните разделы.

## Структура

```markdown
# Название действия (отглагольное существительное)

Одно-два предложения: что вы сделаете и зачем.

## Перед началом

- Что нужно подготовить.
- Какие права нужны.

## Шаги

1. Первое действие.
2. Второе действие.

   Результат: что увидит читатель.

## Результат

Что получилось в итоге.

## Что дальше

- [Ссылка на следующий документ](путь.md)
```

## Требования к разделам

| Раздел | Обязателен | Требования |
| --- | --- | --- |
| Вводный абзац | Да | Не более двух предложений |
| Перед началом | Нет | Только реальные предварительные условия |
| Шаги | Да | Правило [С5](../style/tone.md): один шаг — одно действие |
| Результат | Да | Проверяемый признак, что действие выполнено |
| Что дальше | Нет | Не более трёх ссылок |
