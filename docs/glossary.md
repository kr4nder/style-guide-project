# Глоссарий

Используйте термины из колонки «Пишем». Слова из колонки «Не пишем» в документации не применяются.

| Пишем | Не пишем | Определение |
| --- | --- | --- |
| рабочее пространство | воркспейс, пространство | Учётная запись компании в TaskFlow |
| проект | борд | Набор задач одной команды |
| задача | таска, тикет | Единица работы с названием, исполнителем и сроком |
| исполнитель | ответственный, юзер | Участник проекта, которому назначена задача |
| токен доступа | ключ, токен авторизации | Строка, которая подтверждает права при обращении к API |
| конечная точка | эндпоинт, ручка | Адрес метода API |
| вебхук | хук | Запрос, который TaskFlow отправляет на ваш адрес при событии |
| коммит | комит | Зафиксированное изменение в Git |
| репозиторий | репа | Хранилище файлов проекта в Git |
| Pull Request | пулл-реквест, ПР | Запрос на слияние изменений |
