# Создание проекта

Проект объединяет задачи одной команды.
Создайте проект, чтобы начать работу в TaskFlow.

## Перед началом

- Войдите в TaskFlow.
- Убедитесь, что у вас есть роль «Администратор рабочего пространства».

## Шаги

!!! warning "Внимание"
    Название проекта нельзя изменить после создания.

1. Откройте **Проекты**.
2. Нажмите **Создать проект**.
3. В поле **Название** введите название проекта, например `Сайт компании`.
4. В списке **Исполнители** выберите участников команды.
5. Нажмите **Создать**.

    Результат: откроется страница проекта с пустым списком задач.

## Результат

Проект появился в списке **Проекты**.
Теперь вы можете [создавать задачи](create-task.md).
