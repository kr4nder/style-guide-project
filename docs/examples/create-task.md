# Метод «Создать задачу»

Метод создаёт задачу в указанном проекте.

## Запрос

```text
POST /v1/projects/<project_id>/tasks
```

Где `<project_id>` — идентификатор проекта.

### Заголовки

| Заголовок | Обязателен | Описание |
| --- | --- | --- |
| `Authorization` | Да | Токен доступа в формате `Bearer <access_token>` |
| `Content-Type` | Да | Значение `application/json` |

### Параметры тела запроса

| Параметр | Тип | Обязателен | Описание |
| --- | --- | --- | --- |
| `title` | string | Да | Название задачи, до 200 символов |
| `assignee_id` | string | Нет | Идентификатор исполнителя |
| `due_date` | string | Нет | Срок выполнения в формате ISO 8601 |

### Пример запроса

```bash
curl -X POST https://api.taskflow.example/v1/projects/<project_id>/tasks \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"title": "Подготовить макет", "due_date": "2026-11-02T18:00:00Z"}'
```

## Ответ

В случае успеха метод возвращает код `201 Created`.

### Поля ответа

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | string | Идентификатор созданной задачи |
| `title` | string | Название задачи |
| `created_at` | string | Дата и время создания в формате ISO 8601 |

### Пример ответа

```json
{
  "id": "tsk_1042",
  "title": "Подготовить макет",
  "created_at": "2026-10-26T14:30:00Z"
}
```

## Ошибки

| Код | Описание | Что делать |
| --- | --- | --- |
| `400` | Не указан параметр `title` | Добавьте `title` в тело запроса |
| `401` | Токен доступа недействителен | Получите новый токен |
| `404` | Проект не найден | Проверьте значение `<project_id>` |
