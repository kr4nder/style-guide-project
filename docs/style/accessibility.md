# Доступность текста

Раздел описывает, как писать документацию, которую смогут прочитать люди с нарушениями зрения, слуха, внимания и чтения, а также читатели с медленным интернетом и на мобильных устройствах.
Правила основаны на рекомендациях WCAG 2.2.

## Д1. Простой язык

- Используйте короткие слова и предложения (см. [С4](tone.md)).
- Объясняйте незнакомые термины при первом упоминании или ссылайтесь на [глоссарий](../glossary.md).
- Не используйте метафоры и идиомы: «подвести черту», «из коробки».

## Д2. Структура

- Заголовки отражают содержание страницы, их порядок соответствует [правилу Ф1](formatting.md).
- Начинайте раздел с главной мысли.
- Длинный текст разбивайте на разделы с заголовками.

## Д3. Цвет и контраст

- Не передавайте смысл только цветом. Вместо «красная кнопка» пишите «кнопка **Удалить**».
- Контраст текста и фона — не ниже 4,5:1.

## Д4. Изображения

- Для каждого изображения пишите альтернативный текст: что на нём показано и зачем оно нужно.
- Не начинайте альтернативный текст со слов «изображение» и «картинка».
- Декоративные изображения не добавляйте.
- Текст на скриншотах дублируйте в основном тексте.

| Не так | Так |
| --- | --- |
| `![картинка](img1.png)` | `![Форма создания проекта с полем «Название»](create-project.png)` |

## Д5. Ссылки

- Текст ссылки понятен без окружающего текста: «Правила оформления списков», а не «читайте здесь».
- Не делайте две разные ссылки с одинаковым текстом.
- Если ссылка ведёт на файл, укажите формат и размер: «Шаблон договора (PDF, 2 МБ)».

## Д6. Таблицы

- Используйте строку заголовков.
- Не объединяйте ячейки.
- Не используйте таблицу, если данные можно записать списком.

## Д7. Сокращения

Расшифровывайте сокращение при первом упоминании ([О8](spelling.md)). Не создавайте собственных сокращений.

## Д8. Видео и аудио

- Добавляйте субтитры.
- Дублируйте содержание видео текстовой инструкцией.
- Не запускайте воспроизведение автоматически.

## Проверка

Перед публикацией проверьте:

- [ ] У каждого изображения есть альтернативный текст.
- [ ] Смысл не передан только цветом.
- [ ] Тексты ссылок понятны вне контекста.
- [ ] Страница читается без изображений.
